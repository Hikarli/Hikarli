# Hi, I'm bun

I'm interested in systems, cognition, and how meaning emerges from context.  
Most of my work is exploratory: reading system code, mapping structures, and observing how small details shape behavior—whether in OS kernels, databases, or natural language.

I tend to focus on:
- system-level structure and mechanism  
- context-sensitive patterns (language, interaction, gameplay)  
- how small design choices create large-scale effects  
- learning by reading original sources and implementations  

My repositories are lightweight and honest.  
They reflect what I'm currently exploring rather than polished projects.
